Install

macOS on Apple Silicon or Intel. Pick one way.

🚀 One line recommended

No admin password needed.

$ curl -fsSL https://github.com/apipas/aimeterix/releases/latest/download/install.sh | sh
  • Downloads the right build for your Mac from GitHub
  • Checks its SHA-256
  • Installs it in ~/.local with its own Python
  • Adds aimeterix to your PATH
  • Starts AI Meterix and prints the dashboard address

📦 Installer package

  1. Download the .pkg for your Mac from the releases page:
    • Apple Silicon (M1 and later): ai-meterix-<version>-macos-arm64.pkg
    • Intel: ai-meterix-<version>-macos-x86_64.pkg
  2. Double-click it and follow the steps.
  3. Start AI Meterix in Terminal:
$ aimeterix start

⚠️ The package is not signed yet. If macOS blocks it, open System Settings > Privacy & Security and choose Open Anyway.

🛠️ From source

Needs uv.

$ git clone https://github.com/apipas/aimeterix.git
$ cd aimeterix
$ uv run aimeterix start

▶️ Next steps

  1. Open the dashboard at http://127.0.0.1:8788/. Log in as user, password user; you choose a new password the first time.
  2. Set your electricity price per kWh:
$ aimeterix profile set --rate 0.30
  1. Point your apps at the proxy, for example http://127.0.0.1:8787/openai/v1. To see the address for each provider:
$ aimeterix providers
  1. Check that everything is measuring:
$ aimeterix health
