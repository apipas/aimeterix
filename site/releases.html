0.1.2

Preview: metering, costs and a dashboard on one Mac.

  • Install in one line on macOS, Apple Silicon or Intel, without an admin password. A .pkg and building from source work too.
  • Zero setup: the first aimeterix start sets itself up; aimeterix init is optional.
  • Energy on Apple Silicon: CPU, GPU, memory and power, split by process and by local model.
  • Tokens of every call, streaming included, for ten cloud providers and local models.
  • Costs per day from energy, fixed fees and dated public prices for 53 models.
  • Storage: SQLite, PostgreSQL or DuckDB.
  • Dashboard at 127.0.0.1:8788 with a built-in Help page.
  • Fixes for Python 3.10 and 3.11, proxy connections the provider closed, PostgreSQL sorting and slow starts on macOS.
