AI Meterix @VERSION@ is installed

Open Terminal and run:

aimeterix start

It runs the agent, proxy and dashboard in the background. The first start sets up the default settings. To change them first, run aimeterix init before it. aimeterix health checks that everything is measuring.

Addresses

Dashboardhttp://127.0.0.1:8788/
Accountsuser to read; admin to change settings. The first password is the account name; you choose a new one at first login.
Proxy for your appshttp://127.0.0.1:8787/openai/v1 and one address per provider: aimeterix providers

These are the defaults; aimeterix paths shows the settings file.

Manual

In the dashboardhttp://127.0.0.1:8788/#help: every number, panel and command
In Terminalaimeterix --help, aimeterix paths
On this Mac/usr/local/ai-meterix/docs (README, FAQ, changes, security)

Remove

aimeterix uninstall --purge stops everything, deletes your settings and data, and prints the line that removes the program.
