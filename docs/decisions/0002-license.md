# 0002: License

- Status: accepted
- Date: 2026-10-09
- Plan ref: D0.2

## Context
The owner wants the project free for anyone to use, including commercially, while keeping credit for the original work.

## Decision
**Apache License 2.0**, with a `NOTICE` file that credits the original author: Maher Abuthraa, Apipas s.r.o. (https://apipas.com).

## Consequences
- Anyone may use, modify, sell and embed AI Meterix, including in closed-source products.
- Redistributions must keep the copyright notices and the `NOTICE` file (section 4), so the original author stays credited.
- Includes an explicit patent grant, which companies' legal teams prefer over MIT.
- It does not force others to open-source their changes. If that is ever wanted, a copyleft license (AGPL) would be the alternative, at the cost of fewer companies adopting it.
- Contributions are accepted under the same license (inbound = outbound); no CLA for now.
