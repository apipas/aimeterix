# 0007: How we record decisions

- Status: accepted
- Date: 2026-10-09
- Plan ref: D0.7

## Decision
Every settled decision gets a short record in `docs/decisions/`, numbered in order and using the template in `README.md`. A changed decision gets a new record that supersedes the old one; old records are never rewritten.

## Consequences
- New contributors can see why things are the way they are.
